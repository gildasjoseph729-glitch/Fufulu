# Contributing to Fufulu

Thank you for your interest in contributing to Fufulu! We welcome all types of contributions - code, documentation, bug reports, and feature suggestions.

## 🎯 How to Contribute

### Reporting Bugs
1. Check if the bug has already been reported in [Issues](../../issues)
2. If not, create a new issue with:
   - Clear description of the bug
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable

### Suggesting Features
1. Open a new issue with the tag `enhancement`
2. Describe the feature and why it would be valuable
3. Provide use cases and examples

### Code Contributions
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes with clear commit messages
4. Push to your fork
5. Create a Pull Request with a description of your changes

## 📝 Commit Message Guidelines

- Use clear, descriptive commit messages
- Start with a verb: "Add", "Fix", "Update", "Remove", "Refactor"
- Example: `Add order tracking feature for drivers`

## 🔍 Code Standards

- Follow consistent code style
- Write meaningful comments for complex logic
- Test your changes before submitting
- Update documentation as needed

## 🚀 Development Workflow

1. Create a branch from `main`
2. Make your changes
3. Test thoroughly
4. Submit a pull request
5. Await code review
6. Address any feedback
7. Merge when approved

## ❓ Questions?

Open an issue with your question or check existing discussions.

Thank you for making Fufulu better! 🙏
