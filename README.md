# Fufulu - Food Delivery System for Tanzania 🍽️

A modern, intuitive food delivery application designed specifically for the Tanzanian market. Fufulu provides a seamless experience for customers, restaurants, and delivery drivers with beautiful animations, responsive design, and reliable backend logic.

## 🎯 Vision

Build a food delivery ecosystem that understands and serves Tanzania's unique needs:
- Support for local payment methods
- Optimized for mobile-first users
- Real-time order tracking with GPS integration
- Support for Swahili language interface
- Reliable service in areas with varying network conditions

## 🏗️ Project Architecture

```
Fufulu/
├── frontend/                 # React/React Native UI
├── backend/                  # Node.js/Express API
├── database/                 # Database schemas & migrations
├── docs/                     # Documentation
└── scripts/                  # Utility scripts
```

## 🚀 Core Features

### For Customers
- Browse restaurants and menus
- Real-time order tracking
- Multiple payment options
- Order history and favorites
- Ratings and reviews

### For Restaurants
- Menu management
- Order management dashboard
- Sales analytics
- Driver assignment

### For Drivers
- Order notifications
- GPS navigation
- Earnings tracking
- Customer communication

## 🛠️ Tech Stack

- **Frontend**: React/React Native (with smooth animations)
- **Backend**: Node.js + Express
- **Database**: PostgreSQL
- **Real-time**: Socket.io
- **Maps**: Google Maps API / OpenStreetMap
- **Payment**: Integrated payment gateways

## 📋 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn
- PostgreSQL
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/gildasjoseph729-glitch/Fufulu.git
cd Fufulu

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Run migrations
npm run db:migrate

# Start development server
npm start
```
